# Sombras de la Frontera (Nivel 1: El Desierto)

Videojuego 2D desarrollado en **Unity 6 (6000.x)** para la asignatura impartida por el **Mtro. Gabriel Barrón Rodríguez** en la **Universidad Tecnológica del Norte de Guanajuato (UTNG)**.

---

## Equipo de Desarrollo
* **Karen Anahí Padrón Martínez:** Jugador, salud (vidas), sistema de agua/deshidratación, pickups y UI/HUD.
* **José de Jesús Loredo Melendez:** Escenario modular continuo, patrulla de coyotes/policías, linternas con raycast, fauna y coberturas.
